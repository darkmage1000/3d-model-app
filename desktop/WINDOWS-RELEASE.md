Meshcraft creates original low-poly creatures, humans, and props for videogame projects. This release includes editable human appearance presets, giant creature sizing, rigging, animation previews, and GLB / OBJ exports.

## Install in your Desktop folder

1. Download **Meshcraft-Setup-1.1.0-Windows-x64.exe** from the Assets list below.
2. Open the downloaded installer on your Windows PC.
3. At the installation folder screen, click **Browse**, select your **Desktop**, and create a folder named **3d model app**.
4. Install into that folder and finish setup. Use the Meshcraft desktop shortcut to open the app again.

Alternatively, extract **Meshcraft-1.1.0-Windows-x64.zip** into **Desktop / 3d model app** and open **Meshcraft.exe**. Extract the entire ZIP before launching.

Requires Windows 10 or 11, 64-bit. The app works offline. This installer has no code-signing certificate. Keep your saved characters when updating; the desktop app stores them in your Windows user profile.
